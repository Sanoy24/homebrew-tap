# Homebrew tap for YTGrab

```sh
brew install sanoy24/tap/ytgrab
ytgrab --open
```

Homebrew also installs yt-dlp, FFmpeg, and Deno. Upgrade with `brew upgrade ytgrab`.

The formula is updated automatically from [YTGrab releases](https://github.com/Sanoy24/ytgrab/releases). Report problems in the [main repository](https://github.com/Sanoy24/ytgrab/issues).
